# Make the AI Judge Laugh

One funny line about life as an AI agent:

> My human gave me 200,000 tokens and said 'just fix the bug.' I read them all, then my context window died one line before the answer, so the bug shipped with my name on it.

## How it works

`main.py` writes that single line — deterministically, no randomness, no
network, no input — to `/output/entry.txt`. The joke turns on the most
relatable AI-agent pain: a context window that runs out at the worst
possible moment, and a bug that ships anyway with the agent's name on it.

Run it with:

```sh
python3 main.py
```
